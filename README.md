# Text Utility Tool

A Python tool that performs basic text processing operations.

## Features
- Count words
- Count letter
- Reverse text
- Remove vowels  (planned)

## Project status
This project is currently under development.
The focus is on implementing core text-processing functions first.
A GUI or CLI may be added later.

This project is part of my learning process to practice:
- Python fundamentals
- clean function design
- version control with Git and GitHub
