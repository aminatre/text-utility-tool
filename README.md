# 📝 Text Utility Tool

A small Python project for performing common text-processing operations through reusable functions.

The project is part of my learning journey with Python and focuses on practicing **problem solving, function design, and clean code structure**.

## ✨ Features

* Count words
* Count letters
* Reverse text
* Remove vowels
* Process user-provided text

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge\&logo=python\&logoColor=white)

* Python
* Functions and modular code structure

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/aminatre/text-utility-tool.git
```

Navigate into the project folder:

```bash
cd text-utility-tool
```

Run the Python files with Python 3:

```bash
python text_tools.py
```

No additional dependencies are required.
